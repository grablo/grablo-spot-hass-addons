# Grablo Spot

Run Grablo Spot next to Home Assistant. Grablo Spot adds AI search and alerts to the IP
cameras you already have: find people and vehicles in your recordings, search by
description, and get notified when something you care about appears.

## Installation

1. Install the add-on and press **Start**.
2. Open the local screen at `http://<your-home-assistant-host>:8127/` and create the admin
   account. On first start the setup code is printed in the add-on **Log** tab.
3. Add your cameras and press **Start**.

You can also add the device in the **[Grablo Spot web app](https://spot.grablo.co)** to use
it from anywhere.

## Grablo Spot and Grablo IoT Core

Grablo Spot is a separate add-on from Grablo IoT Core, with its own version line.
Home Assistant keeps each add-on's data separately, so if you move from the Grablo IoT Core
add-on to this one, add the device again in the web app.
