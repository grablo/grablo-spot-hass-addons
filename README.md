# Grablo Spot Home Assistant Add-on

Official [Home Assistant](https://www.home-assistant.io/) add-on repository for
[Grablo Spot](https://grablo.co).

**Grablo Spot** adds AI search and alerts to the IP cameras you already have: find
people and vehicles in your recordings, search by description, and get notified when
something you care about appears.

## Installation

Click the button below:

[![Open your Home Assistant instance and show the add add-on repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fgrablo%2Fgrablo-spot-hass-addons)

Or, in your Home Assistant, navigate to **Settings > Apps > App store > ⋮ >
Repositories** and add `https://github.com/grablo/grablo-spot-hass-addons` to the list.

Then find **Grablo Spot** in the store and press **Install**.

## Add-ons in this repository

### [Grablo Spot](grablo-spot/)

Open the local screen at `http://<your-home-assistant-host>:8127/`, or use the
[Grablo Spot web app](https://spot.grablo.co). See the add-on's
[documentation](grablo-spot/DOCS.md).
